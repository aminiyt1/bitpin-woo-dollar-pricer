## 📌 معرفی

**Bitpin WooCommerce Dollar Pricing** یک افزونه رایگان برای وردپرس و WooCommerce است که به شما اجازه می‌دهد برای محصولات فروشگاه، یک **قیمت ثابت دلاری (USD)** تعیین کنید.

افزونه به‌صورت خودکار نرخ **USDT/IRT** را از API صرافی **Bitpin** دریافت کرده و قیمت نهایی محصول را بر اساس آن محاسبه می‌کند.

به این ترتیب، به‌جای اینکه قیمت محصولات دلاری خود را هر روز به‌صورت دستی تغییر دهید، کافی است قیمت دلاری محصول را یک‌بار مشخص کنید.

### فرمول محاسبه

```text
قیمت محصول = قیمت دلاری × نرخ USDT/IRT
```

در صورت فعال بودن تعدیل قیمت:

```text
قیمت نهایی = (قیمت دلاری × نرخ ارز) × (1 + درصد تعدیل / 100)
```

سپس قیمت نهایی طبق مقدار تعیین‌شده توسط شما گرد می‌شود.

# 🎯 مناسب چه فروشگاه‌هایی است؟

این افزونه برای فروشگاه‌هایی مناسب است که قیمت محصولاتشان به دلار یا ارز وابسته است و می‌خواهند قیمت ریالی/تومانی محصولات به‌صورت خودکار با تغییر نرخ ارز تغییر کند.

برای مثال:

```text
قیمت محصول: $5

نرخ USDT:
150,000 تومان

قیمت فروشگاه:
5 × 150,000 = 750,000 تومان
```

اگر نرخ ارز به:

```text
160,000 تومان
```

تغییر کند، افزونه در بروزرسانی بعدی قیمت محصول را به:

```text
800,000 تومان
```

تغییر می‌دهد.

# 🔀 پشتیبانی از محصولات متغیر

یکی از قابلیت‌های مهم افزونه، پشتیبانی از **WooCommerce Variable Products** است.

برای هر Variation می‌توانید قیمت دلاری جداگانه تعیین کنید.

مثلاً:

| Variation | قیمت دلاری | قیمت محاسبه‌شده |
| --------- | ---------: | --------------: |
| 1 ماهه    |         $5 |   750,000 تومان |
| 3 ماهه    |        $12 | 1,800,000 تومان |
| 6 ماهه    |        $20 | 3,000,000 تومان |
| 1 ساله    |        $35 | 5,250,000 تومان |

اگر قیمت دلاری یک Variation خالی باشد، افزونه آن Variation را مدیریت نمی‌کند.

## تعدیل قیمت

می‌توانید قبل از ذخیره قیمت نهایی، درصدی به قیمت اضافه یا از آن کم کنید.

مثلاً:

```text
10
```

یعنی:

```text
+10%
```

و:

```text
-5
```

یعنی:

```text
-5%
```

مثال:

```text
قیمت پایه = 1,000,000 تومان

تعدیل = 10%

قیمت نهایی = 1,100,000 تومان
```

# 🛒 نحوه استفاده

## محصول ساده

برای استفاده در یک محصول ساده:

1. وارد ویرایش محصول شوید.
2. به بخش **اطلاعات محصول** بروید.
3. در قسمت قیمت‌گذاری، فیلد **قیمت ثابت دلاری** را پیدا کنید.
4. قیمت دلاری محصول را وارد کنید.
5. محصول را ذخیره کنید.

مثلاً:

```text
قیمت ثابت دلاری: 9.99
```

از این پس افزونه قیمت محصول را بر اساس نرخ ارز Bitpin محاسبه خواهد کرد.

---

## محصول متغیر

برای محصولات Variable:

1. محصول متغیر را ویرایش کنید.
2. وارد بخش **Variations** شوید.
3. Variation موردنظر را باز کنید.
4. فیلد **قیمت ثابت دلاری این متغیر** را پیدا کنید.
5. قیمت دلاری آن Variation را وارد کنید.
6. محصول را ذخیره کنید.

برای هر Variation می‌توانید قیمت دلاری متفاوتی داشته باشید.

---

# 🚫 اگر قیمت دلاری خالی باشد چه اتفاقی می‌افتد؟

اگر فیلد قیمت دلاری یک محصول یا Variation خالی باشد:

> افزونه آن محصول/Variation را مدیریت نمی‌کند.

بنابراین قیمت آن مورد توسط افزونه تغییر نخواهد کرد.

این ویژگی باعث می‌شود بتوانید فقط محصولات یا Variationهای موردنظر خود را وارد سیستم قیمت‌گذاری دلاری کنید.

# 🔄 نحوه بروزرسانی قیمت‌ها

افزونه پس از فعال‌سازی، یک وظیفه زمان‌بندی‌شده WordPress ایجاد می‌کند که **هر ساعت** اجرا می‌شود.

در هر اجرا:

```text
Bitpin API
     ↓
دریافت نرخ USDT/IRT
     ↓
پیدا کردن محصولات دارای قیمت دلاری
     ↓
محاسبه قیمت
     ↓
اعمال تعدیل
     ↓
گرد کردن قیمت
     ↓
ذخیره قیمت در WooCommerce
```

همچنین می‌توانید از صفحه تنظیمات، بدون منتظر ماندن برای اجرای زمان‌بندی‌شده، گزینه:

**«دریافت نرخ و بروزرسانی محصولات الان»**

را انتخاب کنید.

# 🧮 نحوه محاسبه قیمت

فرض کنید:

```text
قیمت دلاری = $12

نرخ USDT = 150,000 تومان

تعدیل = 10%

گرد کردن = 1,000
```

ابتدا:

```text
12 × 150,000
= 1,800,000
```

سپس تعدیل ۱۰٪:

```text
1,800,000 × 1.10
= 1,980,000
```

در نهایت قیمت بر اساس مقدار گرد کردن تنظیم می‌شود:

```text
قیمت نهایی = 1,980,000 تومان
```

# ⚠️ نکات مهم

### 1. WooCommerce باید فعال باشد

این افزونه برای WooCommerce طراحی شده و بدون WooCommerce فعالیتی انجام نمی‌دهد.

### 2. قیمت دلاری باید بیشتر از صفر باشد

قیمت‌های دلاری نامعتبر توسط افزونه مدیریت نمی‌شوند.

### 3. نرخ ارز از API دریافت می‌شود

برای بروزرسانی خودکار قیمت‌ها، سرور وردپرس باید بتواند به API تنظیم‌شده دسترسی داشته باشد.

### 4. Cron وردپرس

بروزرسانی خودکار قیمت‌ها از سیستم زمان‌بندی WordPress استفاده می‌کند.

اگر WP-Cron روی سایت شما غیرفعال باشد، بهتر است یک **Server Cron** مناسب برای اجرای `wp-cron.php` تنظیم کنید.
